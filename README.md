# プロンプト辞書 フィードバック

[プロンプト辞書](https://prompt-dict.pages.dev/)(日本語で打つだけで、画像生成AIのタグにできる Web サイト)への、不具合の報告・タグの訂正・要望を受け付ける場所です。

## 送り方

[Issue を書く](../../issues/new/choose) から、内容に合うフォームを選んでください。

| フォーム | こんなとき |
|---|---|
| タグの変換・訳の訂正 | 日本語が違うタグに変換された、タグの日本語訳やジャンルがおかしい |
| 不具合 | 動かない、表示が崩れる、思った動きにならない |
| 要望 | こんな機能がほしい、ここを使いやすくしてほしい |

- 書く前に、[同じ内容の Issue](../../issues) がないか見てみてください。あれば、そこに 👍 やコメントを付けてもらえると助かります
- Issue は誰でも見られます。名前やメールアドレスなどの個人情報は書かないでください

## このリポジトリについて

このリポジトリは Issue を受け付けるためだけのもので、サイトのソースコードは置いていません。プルリクエストは受け付けていません(開かれたものは自動で閉じます)。
